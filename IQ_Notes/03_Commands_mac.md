# VS Code Commands (macOS)

Essential VS Code keyboard shortcuts for JavaScript / Playwright development on macOS.

---

## General Editor

| Action | Shortcut |
|--------|----------|
| Command Palette | `Cmd + Shift + P` |
| Quick Open / Go to File | `Cmd + P` |
| Open Settings | `Cmd + ,` |
| Toggle Sidebar | `Cmd + B` |
| Toggle Terminal | `Ctrl + \`` |
| Toggle Zen Mode | `Cmd + K` then `Z` |
| Close Tab | `Cmd + W` |
| Reopen Closed Tab | `Cmd + Shift + T` |
| Close Editor Group | `Cmd + K` then `W` |
| Split Editor | `Cmd + \` |
| Switch Between Editors | `Cmd + 1` / `2` / `3` |

## File Operations

| Action | Shortcut |
|--------|----------|
| Save | `Cmd + S` |
| Save All | `Cmd + Option + S` |
| Open File (from sidebar) | `Enter` |
| Open File in New Tab | `Enter` (single click) |

## Git Integration

| Action | Shortcut |
|--------|----------|
| Open Source Control | `Cmd + Shift + G` |
| Stage / Unstage (on file) | `Cmd + Shift + G` then `Cmd + S` |
| Stage Selected Lines | `Cmd + K` then `Cmd + S` (in diff view) |
| Commit | `Cmd + Enter` (in Source Control input) |
| Pull (via command) | `Cmd + Shift + P` → `Git: Pull` |
| Push (via command) | `Cmd + Shift + P` → `Git: Push` |
| Open Diff Editor | `Cmd + Shift + G` then click changed file |
| View Git History (with GitLens) | `Cmd + Shift + G` → click file |

## Quick Reference — Most Used

```
Cmd + P           → Open file quickly
Cmd + Shift + P   → Command Palette
Cmd + /           → Toggle comment
Cmd + D           → Select next occurrence
Cmd + Shift + L   → Select all occurrences
Cmd + B           → Toggle sidebar
Ctrl + `          → Toggle terminal
Cmd + `           → Switch between VS Code windows
Option + Up/Down  → Move line
Shift + Option + F → Format document
F5                → Start debugging
Cmd + ,           → Settings
```

> **Tip:** Run `Cmd + K` then `Cmd + S` to see / search all available keyboard shortcuts inside VS Code itself.
